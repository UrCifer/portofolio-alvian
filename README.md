   - **Frontend**: HTML, CSS, JavaScript | **Backend**: Python, REST API, MySQL
2. **Krempe — Website E-Commerce Penjualan Keripik Tempe**:
   - Platform e-commerce berbasis web untuk katalog produk keripik tempe dengan varian rasa Original dan Balado, detail berat 200g, masa simpan, level kepedasan, dan tombol beli langsung.
   - **Frontend**: HTML, CSS, JavaScript | **Backend**: Python
3. **ListKu — Website Task Manager & To-Do List**:
   - Aplikasi manajemen tugas harian berbasis web untuk mengelola pekerjaan harian dengan fitur tambah tugas baru, checklist selesai, hapus tugas, serta integrasi kalender harian di web browser.
   - **Frontend**: HTML, CSS, JavaScript | **Backend**: Python
4. **E-Book — Website Platform Perpustakaan Digital**:
   - Platform membaca digital berbasis web dengan koleksi buku gratis dan premium (menampilkan buku *Filosofi Teras* karya Henry Manampiring, *Indigo*, dan *Mahram Untuk Najwa*).

   - **Frontend**: HTML, CSS, JavaScript | **Backend**: Python, PHP, MySQL
6. **ERP System — Website Inventori & Master Data Gudang (PT Alritek Equipindo Jaya)**:
   - Sistem ERP internal berbasis web untuk master data sparepart mesin, pelacakan stok inventori, dan pemesanan supplier di lingkungan industri.
   - **Frontend**: HTML, CSS, JavaScript, Tailwind CSS | **Backend**: Python, PHP, Laravel, MySQL
7. **SPK SAW — Website Pemilihan Karyawan Terbaik & Analisis Sensitivitas (PT Alritek Equipindo Jaya)**:
   - Aplikasi Sistem Pendukung Keputusan (SPK) berbasis web dengan modul simulasi interaktif Analisis Sensitivitas bobot kriteria (Kerajinan C1 50%, Kehadiran C2 40%, Lembur C3 10%), perbandingan ranking dinamis real-time, dan penetapan karyawan terbaik.
   - **Frontend**: HTML, CSS, JavaScript | **Backend**: Python (Algoritma SAW), PHP, Laravel, MySQL
